新增应用内更新和会话录音。

## 新增

- **应用内更新**：通过 Sparkle 在后台检查新版本，一键下载、安装并重启；更新包经 EdDSA 签名校验。应用菜单「检查更新…」可手动检查，「设置 › 通用 › 更新」可关闭自动检查。
- **会话录音**：「设置 › 通用」新增「同时保存录音」（默认关闭），两侧的原声和播放出来的译声各保存为一个 AAC 文件，共用同一条时间轴，与会话字幕放在一起；「历史」页可在访达中显示，删除会话时一并删除。

**从 1.0.0 升级需要手动更新这一次**（Homebrew 用户执行 `brew upgrade --cask livetranslate-bridge`），之后的版本会自动提示更新。

完整变更见 [CHANGELOG](https://github.com/hoobnn/livetranslate-bridge/blob/main/CHANGELOG.md#110---2026-10-09)。

## 安装

```bash
brew install --cask hoobnn/tap/livetranslate-bridge
```

或下载下方经过签名和公证的 dmg。

要求 macOS 27 或更高版本、Apple Silicon。
