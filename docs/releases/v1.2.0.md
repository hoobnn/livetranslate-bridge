新增豆包同声传译 2.0 和 AI 代聊。

## 新增

- **豆包同声传译 2.0**：「设置 › 凭据」可把翻译服务切换为火山引擎豆包同声传译 2.0，支持中、英、日、法、德、西互译（其中一方须为中文或英语）；打开「克隆声音」后用说话人自己的音色播报译文。原有百炼翻译不受影响。
- **AI 代聊**：按通话目标和参考资料，用对方的语言替你应答，字幕板实时显示双方内容。随时开口或点「接管」即可介入，点「交还给 AI」后它会带上最近的对话和你的更正继续。默认使用豆包端到端实时语音（当前支持中英通话），也可切换到「Chat + 豆包 TTS」模式。
- **实时语音声纹训练**：在「设置 › AI 代聊」上传本人录音训练音色、查询状态，成功后用于实时通话。需要 API Key 开通音色服务和声音复刻权限。

配置步骤见 [README](https://github.com/hoobnn/livetranslate-bridge#ai-代聊)。已安装 1.1.x 的用户会收到应用内更新提示；Homebrew 用户也可执行 `brew upgrade --cask livetranslate-bridge`。

完整变更见 [CHANGELOG](https://github.com/hoobnn/livetranslate-bridge/blob/main/CHANGELOG.md#120---2026-10-27)。

## 安装

```bash
brew install --cask hoobnn/tap/livetranslate-bridge
```

或下载下方经过签名和公证的 dmg。

要求 macOS 27 或更高版本、Apple Silicon。
