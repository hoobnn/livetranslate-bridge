## 变更

- **产品名统一为 LiveTranslate Bridge**：英文界面的应用名、主窗口标题、安装镜像卷名和项目主页统一使用这一写法。功能、设置、会话历史和已保存的密钥均不受影响。

已安装 1.1.0 的用户会收到应用内更新提示；Homebrew 用户也可执行 `brew upgrade --cask livetranslate-bridge`。

完整变更见 [CHANGELOG](https://github.com/hoobnn/livetranslate-bridge/blob/main/CHANGELOG.md#111---2026-10-10)。

## 安装

```bash
brew install --cask hoobnn/tap/livetranslate-bridge
```

或下载下方经过签名和公证的 dmg。

要求 macOS 27 或更高版本、Apple Silicon。
