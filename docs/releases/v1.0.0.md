首个公开版本：采集任意应用的声音和麦克风，接入 Qwen 实时模型做双向翻译或转录，并把原声和译声分别送到指定的输出设备。

## 亮点

- **双向翻译 / 转录**：对方和我的话各自译成对方的语言，或只记录原话；字幕按时间交错显示在左右两栏。
- **任选声音来源**：接力通话、会议、浏览器、播放器等任意应用，多进程应用一并采集。
- **音频路由**：两侧输出设备分别指定，原声和译声音量各自可调（0–200%），可配合 BlackHole 让对方听到译文。
- **音色复刻、术语表、聚合设备麦克风**。
- **会话历史**：字幕自动保存在本机，可在「历史」页回看、搜索、删除；只保存文字，不保存音频。
- **导出为文档**：导出为 Markdown、纯文本或 Word（.docx），快捷键 ⇧⌘E。
- **诊断面板**：进程状态、电平、离线回放自检，以及清理残留的聚合设备。
- **省用量**：静音时暂停上传，译声音量为 0 时只请求文字。

完整变更见 [CHANGELOG](https://github.com/hoobnn/livetranslate-bridge/blob/main/CHANGELOG.md#100---2026-09-28)。

## 安装

```bash
brew install --cask hoobnn/tap/livetranslate-bridge
```

或下载下方经过签名和公证的 dmg。

要求 macOS 27 或更高版本、Apple Silicon。
